# Repository Instructions

## Cross-Session Continuity

`PROJECT_PROGRESS.md` is the canonical project state and handoff document.

- Read it completely before planning or changing the project.
- Reconcile it with the actual repository state; the repository is authoritative
  when they differ.
- Use its **Next Actions** as the default priority unless the user says otherwise.
- Before ending a work session, update its current snapshot, workstream, next
  actions, completed milestones, blockers, risks, open questions, decision log,
  verification record, technical map, and session log wherever the session changed
  them.
- Keep the session log newest-first and preserve historical entries.
- Never record secrets, credentials, tokens, or sensitive personal data in it.
